# Getting Started with Next.js 15

Next.js 15 brings exciting new features and improvements to the React ecosystem.

## What's New

- Improved performance
- Better TypeScript support
- Enhanced developer experience

## Getting Started

First, create a new Next.js project:

```bash
npx create-next-app@latest my-app
```

Then navigate to your project:

```bash
cd my-app
npm run dev
```

## Conclusion

Next.js 15 is a powerful framework for building modern web applications.
