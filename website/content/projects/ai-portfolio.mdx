# AI-Powered Portfolio Website

A modern, fully-featured portfolio website with an integrated AI chat assistant.

## Features

- 🎨 Beautiful UI with DaisyUI and Motion animations
- 🤖 AI-powered chat assistant using Google AI
- 📝 Blog with MDX support
- 💼 Experience showcase
- 📬 Contact form with Resend integration
- 🎯 Fully responsive and accessible

## Tech Stack

- **Framework:** Next.js 15 with App Router
- **Styling:** Tailwind CSS + DaisyUI
- **Animations:** Motion/React
- **AI:** Vercel AI SDK + Google AI
- **Content:** Velite for MDX processing
- **Forms:** React Hook Form + Zod
- **Email:** Resend

## Highlights

The website features a modern atomic design system with reusable components, smooth animations, and an AI assistant that can answer questions about the portfolio owner's experience and projects.
